Fermat factorization

If p and q are abnormally close together, n = p×q can be written as a difference of squares and factored almost instantly by walking up from √n. Drag the slider toward a smaller gap to watch the attack go from hopeless to instantaneous.

Wiener's attack

If the private exponent d is smaller than roughly (1/3)·n0.25, it can be recovered from the continued-fraction expansion of e/n alone. For a 1024-bit n that bound is about 254 bits — cross it and the attack should start failing.

Hastad's broadcast attack

Encrypt the same message under e=3 to three or more recipients with different moduli, and the message pops right out via CRT + an integer cube root — no private key needed. Try fewer than 3 ciphertexts to see it fail.

Common modulus attack

Two "users" misconfigured to share one modulus n, each with their own exponent. Given both ciphertexts of the same message, Bezout's identity recovers the message with no factoring and no private key, regardless of modulus size.

Batch GCD

If two "independent" RSA keys secretly share one prime factor (low-entropy key generation on embedded devices has caused this in the real world), a single gcd() call breaks both — no factoring algorithm at all. Larger pools mean more pairwise comparisons.
